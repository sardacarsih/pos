Cara memasang

  1. Unduh file APK di atas memakai Chrome di HP Android, sebaiknya lewat Wi-Fi.
  2. Ketuk file yang sudah diunduh. Jika diminta, izinkan Pasang aplikasi tidak dikenal untuk Chrome.
  3. Jika aplikasi lama sudah ada dan pemasangan ditolak, copot dulu aplikasi lama, lalu ulangi.
  4. Ketuk Pasang, lalu buka aplikasi dan masuk dengan akun Anda.
